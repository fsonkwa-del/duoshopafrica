Disposition mobile 360 px ; ordre de lecture clavier identique à l'ordre visuel. Chaque écran a titre, retour, action principale et état d'erreur près de la zone concernée.

## Produit / groupe

```text
[Retour]                     [Partager]
[Galerie optimisée, dimensions réservées]
```

Groupe : participants nécessaires sans exposer les identités, échéance absolue localisée, condition de formation, annulation, CTA rejoindre désactivé si complet/expiré.

## Marchand / administration

Mobile : synthèse → commandes à traiter → liste produits → action ajouter. Édition produit en sections identité/variantes/prix/stock/photos ; erreurs conservant les saisies. Bureau : navigation latérale, filtres, liste paginée et panneau détail.
Admin : liste demandes → pièces privées nécessaires au rôle → décision motivée → confirmation → audit lié ; support voit chronologie, finance voit écritures et rapprochement. Aucune action globale destructive dans une simple ligne de tableau.

## Couverture et limites

Ces schémas décrivent les futurs parcours ; le web livré expose seulement une page FR/EN de fondations avec bannière explicite, liens langue et ancre de parcours. Aucun bouton d'achat factice. Validation UX avec acheteurs et marchands de Douala à effectuer.
